# Rule-Based Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python. It interacts with the user through the console and provides predefined responses based on the user's input.

## Features

* Responds to greetings
* Answers simple questions
* Uses predefined responses
* Continues chatting using a loop
* Exits when the user types "bye"

## Technologies Used

* Python
* VS Code

## Concepts Used

* if-elif-else
* Functions
* while loop
* Input and Output
* Strings

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python chatbot.py
```

## Example

```text
You: hello
Bot: Hi! Nice to meet you!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye! Have a great day!
```
